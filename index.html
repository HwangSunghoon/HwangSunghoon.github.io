Data Analysis

Used Car Price Analysis

엔카 일반·판매 완료 매물과 현대·기아 인증중고차 데이터를 활용해 국내 중고차 가격 형성 요인을 분석한 응용데이터분석 프로젝트입니다.

  • 연식, 주행거리, 옵션, 사고 이력, 수급 및 인증 여부의 가격 영향 분석
  • 회귀분석, 상호작용항, ANOVA F-test, 군집분석을 활용한 세 가지 가설 검증
  • 크롤링·상세 정보 보강부터 전처리, 시각화, 최종 보고서 작성까지 수행

An applied data analysis project investigating the factors that shape used-car prices in Korea using Encar listings, sold vehicles, and Hyundai/Kia certified-used-car data.

  • Analyzed depreciation, options, accident history, supply constraints, and certification premiums
  • Tested three hypotheses using regression, interaction terms, ANOVA F-tests, and clustering
  • Covered the full workflow from crawling and enrichment to preprocessing, visualization, and reporting

iOS App

LLM Widget iOS App

SwiftUI와 WidgetKit을 기반으로 홈 화면 위젯에서 미리 설정한 프롬프트를 실행하고, LLM이 생성한 요약 응답을 빠르게 확인할 수 있는 iOS 앱입니다.

  • WidgetKit과 App Intents를 활용한 빠른 프롬프트 실행
  • OpenAI API 연동 및 제목과 핵심 항목 형태의 구조화된 응답
  • App Group 저장소를 통한 앱·위젯 간 설정 및 데이터 공유

An iOS app built with SwiftUI and WidgetKit that runs predefined prompts from the home-screen widget and displays concise LLM-generated summaries.

  • Quick prompt execution with WidgetKit and App Intents
  • OpenAI API integration with structured title-and-bullet responses
  • Shared settings and data between the app and widget through an App Group

AI Service

Shopping AI Agent

자연어 쇼핑 검색과 추천, 조건 누적형 후속 탐색을 지원하며 AI가 상품 탐색을 보조하도록 설계한 쇼핑 검색 서비스입니다.

  • LLM과 규칙 기반 fallback을 결합한 가격·용도·기능·브랜드 조건 해석
  • 네이버 쇼핑 API 후보 수집 후 가격, 리뷰, 배송, 선호도, 대화 문맥 기반 재정렬
  • Next.js 15, FastAPI, SQLite로 구현하고 AWS EC2·Nginx·systemd 배포 구조 구성

A shopping search service supporting natural-language queries, recommendations, and context-aware refinement while keeping product discovery at the center of the experience.

  • LLM-based condition parsing with rule-based fallback for price, use case, features, and brands
  • Naver Shopping API retrieval followed by reranking using price, reviews, delivery, preferences, and conversation context
  • Built with Next.js 15, FastAPI, and SQLite, with an AWS EC2, Nginx, and systemd deployment setup
